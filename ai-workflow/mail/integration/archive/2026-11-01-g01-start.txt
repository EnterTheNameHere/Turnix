Backend seam (backend/observation.py only): ctx.observations.export(session) issues
ObservationReadGrant for an explicitly selected same-owner session, under valid
invocation and ApplicationRun authority. grant.snapshot() returns frozen publication
evidence (opaque sessionId, composition clockEpochId, lifetime, request and existing
ObservationSnapshot); grant.revoke()/revoked concern only that read authority.
ctx.observations.bindReadGrant(grant) validates same application and derives an
independently revocable bridge access claim whose reading also depends on its parent.
No inference/source release/subscribe/registry discovery is delegated; no context or
validation callback is retained. Grants acquire no collector or source lifetime claim.
Source release invalidates all its read grants; parent revoke invalidates dependent
bridge reads. RUN invalidation is unchanged. No context module change is anticipated.

Pack: observation.bridge, modPack version 0.1.0, path first-party/observationBridge.
Explicit ManualActivationPlan activation creates one ephemeral 127.0.0.1 endpoint,
never automatic inference monitoring. Capabilities observation.bridge.publish@1
(payload {grant}) / withdraw@1 ({publicationId}) / connection@1 (no payload).
The publish callback uses its fresh ctx.observations.bindReadGrant before accepting
publication. Registry bounds: at most 8 publications, 512 hardware samples/stream
windows per source request, bounded reply size and last-evidence cache only.
No caller-supplied app identity is trusted. Unrelated grants/source consumers survive
withdrawal; reader HTTP calls acquire no collection claims.

Transport: replaceable standard-library single request-worker loopback HTTP polling,
GET /publications/<opaque-id>, no listing/discovery/mutation route. One random
256-bit per-instance Bearer credential in Authorization, never URLs/logging.
Exact Host 127.0.0.1:<bound-port>, explicit configured browser Origin allowlist
(default none; Origin-free authenticated nonbrowser clients supported). Preflight
validates Origin/Host/method/Authorization header request without returning data.
No wildcard CORS, cookies, external bind, redirects or HTTP access logs. Finite socket
I/O timeout, bounded request backlog and response size; no per-reader worker spawning.
connection capability returns endpoint/credential/allowedOrigins to the authorized
same-app caller. A later G-02 user supplies that connection descriptor and selected
publication URL out of band (copy/paste into viewer), no query credential or ambient
network discovery. Origins configured explicitly for the later viewer's local port.

Revocation ordering: bridge lock serializes publication reads/sends and withdrawal;
withdraw waits in-flight sends, clears cache and revokes only its derived read grant.
Every read revalidates source/parent; revoked sources never serve cached fallback.
Source grant reads linearize under observation service lock; already copied in-flight
responses may complete as caller-owned evidence. No source-lock callback into bridge.
Unload first rejects new requests, withdraws all publications, closes/joins endpoint.
Failed onLoad self-cleans resources before rethrow since PackLoader may pass None
state to onUnload. No retained onLoad/cleanup context or dependency on observation
request authority during shutdown. Hung native read limits remain existing PM limits.
