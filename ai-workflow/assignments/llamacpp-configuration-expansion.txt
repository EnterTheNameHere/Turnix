LC-01: startup MoE/reasoning, compatibility and evidence foundation
-----------------------------------------------------------------
Provide typed startup settings for MoE expert cache MiB and all-expert CPU
placement, retaining cpuMoeLayers and KV/offload controls. Provide server reasoning
mode, effort, budget/message, format, preservation and JSON template kwargs.
Reject invalid exact types/ranges/non-finite numbers and contradictory authorities;
document omission versus explicit off/zero/default. Use actual pinned parser values.
Do not silently change existing profiles into thinking-enabled profiles.

Centralize owned flag/alias conflict checks for structured fields versus extraArgs,
including --flag=value, paired switches and relevant aliases. Parse argv ownership
without mistaking a legitimate string/JSON value beginning with '-' for a flag.
Unknown experimental extraArgs remain possible but are not certified supported;
recognizable removed options and conflicts must fail clearly.

Establish immutable configuration/profile evidence with honest provenance:
requested settings, actual ordered argv for managed launch, build identity and
probe status, and separately any provider-reported effective settings. Identify
target/auxiliary inputs without claiming a path is a content hash. Include startup
settings in shared-driver compatibility/profile identity. External mode must not
claim it applied server-only settings. Define behavior before accepting them.
Support an explicit build/capability check for the pinned surface; a missing or
different binary must not be reported as supported by inference from a version
string. Preserve ordinary fake-driver tests and legacy minimal configurations.
Keep probes bounded, lazy/cached where appropriate and free of model startup.
Do not log prompts, credentials, or raw private evidence indiscriminately.

LC-02: request reasoning, token estimation and output preservation
-----------------------------------------------------------------
Extend validated providerOptions with request template kwargs and reasoning format,
retaining reasoningEffort. Keep server-only controls out of per-call mutation.
Define/test precedence or reject contradictions involving enable_thinking,
reasoning_effort and template effort. Freeze caller-owned nested values.
Verify /apply-template behavior at the pinned source and make the estimator use
equivalent template controls to inference. If exact estimation is unavailable for
a setting, expose that limitation explicitly; do not return a misleading exact count.

Preserve streamed reasoning_content and relevant reasoning metadata separately
from answer text, including reasoning-only chunks and final evidence. Specify
where consumers can retrieve it and test the complete processing/result path,
not merely an isolated parser. Existing event metadata is the first candidate;
escalate any necessary generic schema/query/continuation change before implementing
that change. Never concatenate reasoning into ordinary answer text automatically.
Preserve protocol failures, response closing, cancellation and observation counts.
Do not export raw reasoning/request bodies through telemetry or G-01.
reasoning_control is optional and deferred for this assignment: no new real-time
control endpoint or cancellation lifecycle. Request budget fields beyond the mail's
minimum are also deferred unless explicitly rescoped.

LC-03: speculative decoding and combined compatibility gate
-----------------------------------------------------------
Provide an explicit no-speculation configuration, validated ordered method(s),
draft max/min, auxiliary model path, draft GPU device/layers and relevant sampling/
threshold controls from the pinned parser. Method-specific ngram controls may use
extraArgs initially; document covered and uncovered options individually.
Validate inter-field requirements and reject none mixed with active methods or
draft inputs. Account for upstream metadata inference and inherited environment
settings; --spec-type none alone is not adequate evidence of the baseline.
Do not infer or silently enable drafting merely because a draft model is supplied.
No auxiliary model download, optimizer, universal model compatibility table or
automatic restart policy. Record exact draft configuration and profile identity,
with actual honor still model/backend dependent. Extend LC-01 conflict/evidence
handling rather than introducing a second mechanism.
