independent acceptance ledger. Use linked STATE, assignment, review, mail and actual
branch refs to resolve discrepancies. When a branch is unverified, say UNKNOWN.

who must take the next action. Do not turn these labels into a platform-wide state
machine. Update this board on meaningful task transitions, not every code commit.
