Binding archive implementation clarifications
---------------------------------------------
1. DATA/COMMIT + immutable blob protocol is approved for the declared local process-
   death / OS-still-running model. Keep exact bytes/hash rules, artifact-before-
   COMMIT ordering and flush/fsync before ACK. Test fresh-child exit after actual
   ACK and inspect from another process. Record tested filesystem and directory
   sync availability honestly; neither file fsync nor directory existence proves
   universal power-loss durability. No broader IO rewrite is required.
2. Writer timeout poisons future admissions but cannot revoke an in-progress OS
   write. An eventual valid COMMIT may appear after timeout. Recovery may validate
   it as an on-disk commit with ACK observation unavailable; it must never infer
   execution succeeded or caller ACKed. Timed-out workers/handles retain explicit
   ownership until completion or process exit. Bounded close must not claim a
   stalled worker stopped, race it with a second writer, or force-dispose it.
3. Timer/event thresholds trigger a checkpoint; they are not a wall-clock guarantee
   that disk acknowledged it. Account for pending AND in-flight serialized bytes,
   mandatory commands, artifacts and escaped JSON. Partial caps may truthfully stop
   a fragmented stream; never silently omit content to label evidence complete.
4. Archive failure latch and exact active-Job cancellation must be observed before
   every next turn/unit admission, including timer/background failures without new
   stream events. Worker callbacks/cancellation must not run under writer queue
   locks or backend/domain/transport stop locks. Mandatory waits must observe
   cancellation/deadlines; a stalled sink cannot freeze the cancellation relay.
5. A required pre-send capture callback can fail a call whose provider never sent;
   after-send sink failure cannot manufacture provider uncertainty or clear actual
   UNKNOWN. Preserve actual call/Job/cleanup evidence, first non-Exception exit,
   independent archive failure and later cleanup facts. Never let a final capture
   callback replace an earlier provider/cancellation/interrupt exception.
6. Reader enforces typed payloads/order/limits and validates all referenced blobs
   before projecting a committed record. Torn final data is distinct from a
   complete invalid frame/hash/reference. A valid prefix is useful evidence, not
   complete success in a corrupt archive. Seal is not a close or ACK-return receipt.
   Existing result schemas stay inspectable without being called durable archives.

Binding shared seam clarifications
----------------------------------
7. Required/disabled policy is bound to actual runtime-issued owners at composition,
   independently of whether a ContextVar scope exists. A required owner invoking
   with no scope MUST fail before inference send; absence must not silently opt out.
   A foreign scope must not capture a disabled owner's body. Repeated compose's
   existing-binding fast path must not silently broaden/replace capture policy.
8. ContextVar is a locator, not authority or exclusive ownership. Use an atomic
   one-use claim on an instance-local scope bound to exact owner and admitted call.
   Test copied contexts attempting overlapping and later reuse, cross-thread use,
   wrong broker/owner, nested scopes, close/revocation and concurrent Applications.
   Reject unsupported crossings explicitly. Cleanup can emit bounded final facts
   for its already claimed ticket; it cannot authorize another inference.
9. Actual-owner link is trusted adapter-only identity, excluded from repr, metadata,
   traces and archives. Prefer the smallest identity comparison needed; exposing
   runtime ownership to trusted adapter must not give the App a new execution or
   revocation handle. Existing runtime validation/grants remain authoritative.
10. Capture bytes EXACTLY from the immutable Request.data used by open; do not change
    serialization, requests, transport or token/template/slot traffic. Required
    serialized and attempt ACKs occur before inference open. Callbacks execute
    outside broker/backend/stop locks, with fail-closed lifecycle rechecks before
    send. After serialization/admission failure, release scope and preserve the
    actual unsent/uncertain provider finalization semantics.
11. Report only facts the current transport exposes: successful-open headers may
    be observed; error-path headers may be unavailable. No new transport API is
    required merely to replace unknown with a fact. mayHaveSent is not consumption.
    Do not wrap a late error as not-sent simply because the sink failed.
12. Fixed public failure text alone does not guarantee privacy: test exception
    cause/context formatting, observerErrors, Job/trace/event/profile/PM/G paths
    using distinctive synthetic private content. No ordinary raw sink exception
    should leak a body/path through generic diagnostics. Preserve exact primary
    non-Exception object/precedence; no raw content in secondary diagnostic records.
