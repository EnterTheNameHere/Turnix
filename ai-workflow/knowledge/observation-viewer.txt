PUBLIC MODULE CONTRACTS / SEMANTICS
----------------------------------
model.mjs (independent of HTTP/DOM):
- parseSnapshot(raw): supports only actant.observation-publication@1, validates
  units/bounds/IDs/order/clock kind and selected schema structure. All integer
  evidence uses BigInt from bounded decimal strings; no Number timestamp parsing.
  Frozen allowlisted normalized objects discard private/unknown incoming fields.
- secondsFrom(ns, origin): subtract common BigInt origin before Number conversion.
  timeRange(model,lastSeconds) shares retained/last-10/30/60-second x ranges.
  graphSeries(model,kind) returns interval marks; unknown hardware time is not placed.
- ObservationStore: one latest bounded model; identity/epoch changes reset prior
  association and UI selection. Revision regression in same identity is invalid.
  Freshness uses client monotonic elapsed unchanged-hardware time, not display wall
  time or cross-host/browser-server monotonic subtraction. Initial prior age unknown.

polling.mjs (independent of DOM/graphs):
- connectionConfig(endpoint, publication, credential): explicit literal-loopback
  HTTP endpoint and selected 32-hex ID or matching snapshot URL; reject queries,
  fragments, URL-userinfo, external hosts, default port and foreign selection.
- readPublication(config,signal,fetcher): Bearer GET, maximum body 2 MiB including
  chunked/no-length responses; bounded UTF-8 JSON parse; validate selected publication.
  Fixed status errors never reflect server bodies/exception messages.
- Poller with injectable read/scheduler/cancel: defaults 1 s after completion, 5 s
  abort deadline, minimum interval 250 ms, one pending request including reconnect.
  Generation checks reject obsolete late results; reconnect waits for abort
  settlement. An abort-ignoring injected transport blocks progress rather than
  starting another request. Multiple instances share no cancellation/claims.
  Auth/Origin/withdrawn/revoked/schema errors stop automatic polls; transient
  network/503 retries stay bounded and visibly historical.

UI uses native SVG/textContent, no raw HTML interpretation. Synchronized stream
Unicode characters/second, host CPU/GPU percent, host RAM/VRAM GiB. Exact bytes and
monotonic Ns, stream windows/counts/gaps, collection spans, target/actual cadence,
uncovered intervals and separate display Unix wall time are inspectable. No token
conversion, provider metadata or prompt/response content. Hardware is whole-host,
not application attribution. Bars depict collection intervals; no interpolation or
simultaneity claim. Silence is a measured zero stream window, unavailable is hatched,
blank space has no retained collection. Missing timing is counted, not positioned.
Unrequested/unavailable/no-retained readings are labelled separately. Exact dropped
stream windows and conservative hardware truncation are explicit. At most 512
hardware samples/windows with bounded correlation/per-core input; no accumulated
local history. Scalar decimal evidence is capped at 80 digits; relative plotting is
approximate while inspection preserves exact original counts/bytes/time.

Repeated HTTP success is not freshness. Stale hardware means its newest interval
is unchanged for max(5 s,3 target cadences) since this viewer saw it. Earlier age
unknown; stopped collection is final. Paused state labels retained evidence paused.
401/403/404/410/invalid-schema clear plots and stop polls. Network/503 state may
retain visibly historical last evidence. Explicit reconnect clears prior identity.
Different epochs/session/publication are never combined; wall jumps only display.
