Production implementation
--------------------------
first-party/llmDrivers/llamaCpp/ownedTransport.py owns one HTTP operation and its
raw socket. Connect, send and receive use nonblocking sockets and short bounded
wait slices that check stop. This avoids Windows behavior where shutdown of a
timeout-mode socket alone did not promptly wake a buffered read. The callback
only marks stop/shuts down/closes its exact raw socket; HTTPResponse and its
BufferedReader are finalized by the owning reader. Partial-open/pre-header stop,
repeated stop and one-time final close have explicit ownership. Known pre-send
stop is distinct from possible server acceptance. Address resolution itself is
not promised interruptible. Managed HTTP has no proxy/redirect/reconnect fallback.

executionAdapter.py first verifies the owned native slot is idle, then sends
exactly one request to that slot. Before yielding a first nonterminal SSE event
it attempts to bind a new integer id_task while that slot is actively processing.
It keeps the SSE completion ID separate, rejects stale/non-advancing/native
boolean IDs, and poisons correlation on conflicting stream identity. Existing
managed slot bookkeeping excludes another queued request for that same slot;
independent HTTP clients must not bypass it. This is not hostile-client isolation.

Before finalizing an abort, closeExecution checks that the reader has finished
and the exact process object, residency token and cleanup ticket remain current.
Revocation removes new-execution authority, not the exact ticket's cleanup right.
Two matching same-task idle acknowledgements can confirm quiescence, within at
most two seconds and the request timeout. Slot JSON uses a remaining absolute
deadline and 1 MiB cap through its own owned transport. Wrong/missing/stale IDs,
changed process/generation, malformed replies, deadline expiry, active readers
or uncertain final close stay UNKNOWN. Result caching prevents duplicate
finalization or later evidence from repairing an unknown disposition.

Normal completion retains native terminal/consistent ID/DONE plus owned-slot
idle proof, additionally checking bound task identity when available. No native
debug-log dependency was introduced; logs independently corroborate test evidence.
No universal resumable header/DELETE policy or process recovery was added.
Required retention/physical freshness remain unsupported. External mode unchanged.
