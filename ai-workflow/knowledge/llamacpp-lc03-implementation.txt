Supported first-class startup surface
-------------------------------------
Same driver/model per-field inheritance, explicit null suppression and omission
rules as LC-01; non-null new fields reject in external mode at either scope.
- specMethods: nonempty ordered list of unique pinned method names. ["none"] alone
  explicitly requests disabled configuration; omission leaves upstream unspecified.
- draftMaxTokens, draftMinTokens, draftUbatchSize: exact integers 0..2147483647.
  Min must not exceed resolved max, using pinned omitted defaults 0/3 or validated
  inherited values. Ubatch 0 means upstream target ubatch inheritance.
- draftModelPath: optional nonblank existing local file; never a download selector.
- draftDevices: ordered nonempty list of individual names or ["none"] alone;
  no duplicates/comma-packed names. Actual device availability is unverified.
- draftGpuLayers: signed 32-bit exact integer or auto/all; signed parser behavior
  is preserved rather than incorrectly limiting every placement field to >=0.
- draftSampling: greedy or probabilistic; draftBackendSampling: exact bool.
- draftPMin, draftPSplit: finite exact int/float in [0,1], excluding bool.

The parser accepts broader signed draft-min and probability inputs. This documented
structured subset excludes negative minimums (downstream size_t casts) and values
outside probability ranges. No claims of effective model honor follow validation.
All methods: none, draft-simple, draft-eagle3, draft-mtp, draft-dflash, draft-dspark,
ngram-simple, ngram-map-k, ngram-map-k4v, ngram-mod, ngram-cache.

lists must match this order: ngram-simple, ngram-map-k, ngram-map-k4v, ngram-mod,
ngram-cache, draft-simple, draft-eagle3, draft-mtp, draft-dflash, draft-dspark.

priority claim. Duplicates and none mixed with active methods fail. Multiple active
methods in supported order are allowed, with actual compatibility unverified.

the target's MTP context without an auxiliary path, as in pinned source. Draft
controls require a draft method, and weights never imply/enable a method.
