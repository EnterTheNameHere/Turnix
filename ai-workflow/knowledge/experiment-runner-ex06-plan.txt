03. PROPOSED AUTHORED DEFINITION
--------------------------------
Illustrative complete JSON5 shape (host aliases/config below must be approved):
{
  schemaId: 'actant.experiment.definition@3',
  experimentId: 'python-one-pass', mode: 'classic',
  configurations: [{name: 'baseline', profile: 'qwen',
    defaults: {maxTokens: 1024, timeoutSeconds: 120, temperature: 0},
    allowedOverrides: []}],
  repetitions: 1, errorPolicy: 'stop', contextPolicy: 'fresh-best-effort',
  inputs: {priming: 'prompts/priming.txt', task: 'prompts/task.txt'},
  procedure: [
    {id: 'prime', op: 'message', role: 'user', parts: [
      {input: 'priming'}, {literal: '\n\n'}, {input: 'task'},
      {literal: '\nReturn the complete source in exactly one python fence.'}]},
    {id: 'draft', op: 'inference'},
    {id: 'save', op: 'save', inference: 'draft',
      extract: 'one-python-fence', artifact: 'candidate', path: 'candidate.py'},
    {id: 'fix', op: 'cli', command: 'ruff-safe-fix', artifact: 'candidate'},
    {id: 'format', op: 'cli', command: 'ruff-format', artifact: 'candidate'},
    {id: 'types', op: 'cli', command: 'ty-check', artifact: 'candidate'},
    {id: 'lint', op: 'cli', command: 'ruff-check', artifact: 'candidate'},
    {id: 'feedback', op: 'message', role: 'user', parts: [
      {literal: 'Correct this current source using the diagnostics below.\n'},
      {artifact: 'candidate', revision: 'current'},
      {literal: '\nTYPE CHECK\n'}, {cli: 'types'},
      {literal: '\nLINT\n'}, {cli: 'lint'},
      {literal: '\nReturn the complete corrected source in one python fence.'}]},
    {id: 'corrected', op: 'inference'},
  ],
}

Exact allowed keys per op; no expression/string interpolation language. All IDs
unique, references strictly backward and correctly typed. Message parts are tagged
single-source objects; concatenate in list order with NO implicit separators.
Input is frozen run input; artifact/current reads current validated workspace
revision at that step; cli renders the referenced immutable result as canonical
JSON containing status/exitCode/stdout/stderr. Absent diagnostics are not empty
success. Parts cannot refer to host paths, environment or future/current running IO.
Message roles user/assistant only; authored assistant text is explicitly authored,
not a fabricated model output. Reject unsupported system/tool roles. Priming uses
user text in this first slice; no silent system-to-user conversion.
At inference: require nonempty pending message segment ending in user; merge only
allowed inference overrides with each config's defaults; snapshot exact history,
then infer and append completed answer after required ACK/cleanup. Reasoning stays
separate. Two adjacent message steps do not cause two implicit calls. No inference
without a new user message; no trailing pending messages at successful completion.
Model draft remains in history after Ruff changes file; correction query contains
original user+assistant and the explicitly assembled new user message.
Final corrected answer is archived; no implicit second save/tool pass.

Save supports 'whole-answer' or 'one-python-fence' only, never reasoning/partials.
Strict fence grammar: exactly one fenced block in the answer, opener exactly
```python and closer exactly ``` on their own lines (LF or CRLF), nonempty
body, no nested/unclosed/extra fenced block; exterior prose retained only in full
answer. Extract exact between-fence characters including their line endings;
do not dedent, strip or synthesize newline. Reject ambiguity, wrong language,
oversize, invalid UTF-8 or NUL explicitly. No generated-code execution/import.

depth>32 and >16384 container/scalar nodes. Same schema checks after parsing;
canonical sorted compact UTF-8 JSON allow_nan=False; reject non-JSON types.
JSON5 parse itself needs a lexical bounded-depth/token scan BEFORE recursive

Pin tested json5 version/range in approved Application setup metadata; readers

Semantically identical JSON5 yields identical normalized definition hash; raw

Changed/disappeared originals after freeze do not alter later units. No promise

06. OPERATIONS / FAILURE AND CANCELLATION
-----------------------------------------
Freeze source and all config/host/command options; ACK run inputs/plan. Execute
config-major repetitions sequentially; ACK actual Job/unit plan before model
transition. One run capability owns history, workspace, LLM session and ordered
steps until terminal exit. Message assembles and archives immutable content;
inference uses accepted private wire capture and cleanup before result/history ACK.
Save ACKs original answer reference, extracted bytes and extraction rule, then
materializes and records observed working revision before downstream CLI.

For each CLI: ACK exact resolved request + pre-file digest BEFORE start; invoke
once through shared facade; capture process result and bounded post-file snapshot;
ACK both before next step. Artifact revision increments for each observed snapshot
(digest may be unchanged). Original extracted revision is never overwritten in
archive. Read-only diagnostics changing source is a failure, not ignored.
Every completed mutating call gets post-file observation even for nonzero exits.

normal-completed exit in host allowlist: evidence retained, continue. Thus Ruff
remaining findings and ty findings enter correction message once; suite success
describes procedure completion, never code correctness/lint cleanliness.
Other exit (including CLI usage/internal errors): retain, stop; no correction call.
Resolution/launch/timeout/cancel/output-limit/read/archive failures: retain available
original facts, stop subsequent steps/units; actual Job state remains separate.
Cancellation requested before call prevents admission; during call requires shared
owned-child disposition; after call before ACK means later steps do not run.
Post-error file capture is best effort with its own unavailable/failed reason;
it cannot replace primary failure or establish that tool completed safely.
On uncertain effects, archive pending/unknown operation, never label it not-sent/
not-executed based on absence of result/file; no automatic CLI retry after crash.
No successful procedure projection unless every required step/post-file/CLI outcome
and actual unit boundary validates, cleanup confirmed as required by dependency.
Queued LLM session close still not a release receipt. Preserve independent process,
LLM, Job, workspace, writer, host and signal cleanup facts and first BaseException.
