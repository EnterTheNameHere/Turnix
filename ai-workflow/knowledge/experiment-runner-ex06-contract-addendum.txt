 E(n)=6*n+2 bounds JSON string encoding of <=n raw UTF-8 bytes. Raw captured bytes
 decode to <=3*n UTF-8 bytes under replacement; thus rendered stream cost E(3*n).

 separate reasoning, conservatively reserve2*O even if joint runtime cap smaller.

 M<=messageBytes; reserve message source/content docs E(M)+8192; H+=E(M)+128.

 provider serialization bound B=12*Q+262144 (escaping/envelope reserve for approved
 structured-message driver and bounded request controls; reject unsupported
 serialization shapes whose worst case cannot be bounded),
 require B<=requestBytes for required capture; reserve B+Q+E(2*O)+65536 plus
 existing bounded partial/observation budget. H+=E(O)+128 for answer replay.

 E(O)+2*A+32768; do not rely on dedup savings to pass budget.

literal/CLI feedback and transformed source included, not merely newest prompt.
