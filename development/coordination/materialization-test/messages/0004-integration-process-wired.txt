Available Pack-facing contract
------------------------------
Runtime configuration may contain:

    "processTools": {
        "ruff": "C:/absolute/path/to/ruff.exe",
        "ty": "C:/absolute/path/to/ty.exe"
    }

ApplicationRuntime resolves that host configuration into one
ApplicationRun-owned ProcessToolRegistry and ProcessRunner. Every fresh
CodeEntryContext receives an invocation-bound process facade as:

    ctx.process.run(
        "ruff",
        ("check", "path/to/file.py"),
        workingDirectory=...,
        timeoutSeconds=...,
    )

The result is generic JSON-compatible execution evidence containing logical tool
name, configured/resolved executable, exact argv, cwd, wall-clock start/end,
monotonic duration, exitCode, stdout, and stderr.

A nonzero exit code is a normally completed tool result. Unknown tool,
unresolvable executable, launch/communication failure, or timeout raises
ProcessExecutionError. A retained process facade rejects use after its
CodeEntryContext is invalidated.

Authority boundary
------------------
The CodeEntry selects only a configured logical tool name plus argv/cwd/timeout.
It cannot replace the executable through ctx.process. Host configuration is
detached when ApplicationRuntime is created, so caller mutation cannot retarget
a running ApplicationRun's tool registry.
