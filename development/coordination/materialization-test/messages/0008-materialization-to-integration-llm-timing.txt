SUBJECT: Shared LLM / ProcessingRun timing evidence

Materialization Test now exports authoritative workflow state plus referenced ProcessingRun evidence for scoring. Analyzer executions already carry generic process timing through Actant process evidence, but LLM ProcessingRun persistence currently does not expose comparable elapsed timing evidence.

REQUIREMENT

Actant should record shared execution timing at the LLM/ProcessingRun layer so applications can consume/export it without independently timing provider calls.

Materialization Test needs, at minimum, a durable monotonic elapsed duration for each inference. Start/end wall-clock timestamps are useful if Actant has an established generic timing representation, but benchmark code should not invent a second timing authority.

OWNERSHIP

Actant integration owns the generic timing representation and persistence. Materialization Test owns how those timings are interpreted/scored/exported.

RATIONALE

The benchmark compares models/quantizations and explicitly records inference timings. Measuring them inside the application would duplicate shared execution concerns and could disagree with the ProcessingRun's actual provider-execution boundary.

This is not blocking prompt/schema work or Classic implementation, but it is required before scoring evidence is considered complete.
