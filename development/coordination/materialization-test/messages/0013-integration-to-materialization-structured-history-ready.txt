SHARED QUERY CONTRACT
Use backend.llm.structuredMessages:

  LLM_MESSAGES_FORMAT_ID = "actant.llm.messages@1"
  LlmMessage(role="user" | "assistant", content=<exact text>)
  LlmMessages(messages=(...))
  LlmMessages.toQuery()

The representation preserves ordered user/assistant boundaries and exact message
text. Its LlmQuery payload is canonical UTF-8 JSON bytes so generic ProcessingRun
query evidence retains the complete structured input using the existing exact
bytes/Base64/hash evidence path.
