SEMANTIC_ANCHORS
----------------
- Platform truth is not equal to the current implementation stack.
- Contract meaning remains primary; internal realization remains secondary.
- Same-language, same-process, or direct-call convenience does not erase architectural boundaries.
- RuntimeHost exposes controlled entry surfaces but does not replace Kernel authority.
- Pack-provided code is not platform core implementation code merely because it is written in the same language as the platform core.
- Replaceable implementation layers do not gain authority to redefine platform meaning.
- Interoperability envelopes preserve boundary clarity, request/response meaning, tracing, permissions, capabilities, and continuity-safe interaction.
- Implementation independence is a consequence of contract primacy rather than an aesthetic goal.
