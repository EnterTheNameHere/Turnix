Turnix Assistant Semantic Index inferred term candidates
=======================================================

Purpose
-------
This file records terms discovered during extraction or audit that appear in
assistant-facing extraction/index material but may not appear in the canonical
source document.

It is non-authoritative workflow state. It does not define Turnix semantics.
It does not approve source-document edits by itself.

Why this file exists
--------------------
Extraction can reveal useful latent vocabulary.

A worker or assistant may infer a compact term because a canonical document
already defines the underlying concept strongly enough, even if the source does
not name it that way.

Some inferred terms are useful ASI aliases only.
Some are misleading and should be removed or replaced.
Some may be good candidates for canonical source vocabulary.

This file captures those candidates for supervisor review.

Authority rule
--------------
Inferred-term candidates have no authority by themselves.

They may not be used to patch source documents, extraction records, or ASI index
files without explicit supervisor approval.

The user/supervisor decides which terms, if any, become canonical source terms,
ASI aliases, or rejected terms.

Cloud-oriented review note
--------------------------
This review is intended primarily for stronger cloud LLMs.

The review benefits from broad programming, documentation, schema, API, and
architecture naming patterns. Local LLMs may assist with mechanical detection,
but final semantic classification should prefer a stronger model when possible.

Candidate status values
-----------------------
CANDIDATE
  Recorded for supervisor review.

ASI_ALIAS_ONLY
  Supervisor decided the term is useful for retrieval but should not be added to
  source as canonical vocabulary.

SOURCE_TERM_RECOMMENDED
  Supervisor decided the term should be considered for canonical source wording.

SOURCE_TERM_APPROVED
  Supervisor approved a source patch to add or clarify the term.

REJECTED
  Supervisor decided the term is misleading or should not be used.

SUPERSEDED
  Another term or candidate replaces this one.

APPLIED
  Approved source or ASI change has been applied.

Classification values
---------------------
EXPLICIT_SOURCE_TERM
  The term appears in the canonical source document.

SUPPORTED_INFERRED_TERM
  The term does not appear exactly, but the source strongly defines the concept.

CANONICAL_TERM_CANDIDATE
  The term does not appear exactly and may be worth adding to source as named
  vocabulary.

INDEX_ALIAS_ONLY
  The term is useful for assistant retrieval but should not become source
  vocabulary.

REJECT_OR_REPLACE
  The term is misleading, unsupported, over-specific, or should be replaced.
