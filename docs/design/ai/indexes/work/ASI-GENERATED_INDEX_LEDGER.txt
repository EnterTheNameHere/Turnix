Turnix Assistant Semantic Index generated index ledger
=====================================================

Purpose
-------
This file tracks generated Assistant Semantic Index artifacts.

It is non-authoritative workflow state. It does not define Turnix semantics.

Why this file exists
--------------------
The main workflow status ledger tracks source-document extraction records.
Generated ASI files are synthesized artifacts, not source documents, so they are
tracked here separately.

-------------

GENERATED
UPDATED
TESTED_PASS
NEEDS_REVISION
SUPERSEDED
BLOCKED
