Turnix Assistant Semantic Index source improvement candidates
=============================================================

Purpose
-------
This file records possible improvements to canonical Turnix source documents
found during Assistant Semantic Index extraction and review.

It is non-authoritative workflow state. It does not define Turnix semantics.
It does not approve source-document edits by itself.

Why this file exists
--------------------
The extraction process can reveal source-document ambiguity, missing boundaries,
term confusion, cross-document mismatch, or semantic gaps.

When a canonical source document can reasonably be made clearer, Turnix should
prefer improving the source document over permanently compensating with an
external assistant index workaround.

Source clarity first
--------------------
If extraction reveals that a canonical document can easily be misunderstood,
record the finding here as a source-document improvement candidate.

The supervisor decides whether the issue is:
- source-document clarity problem
- ASI routing problem
- extraction wording problem
- real semantic gap
- deferred until related documents are extracted

If a source document can be clarified without changing intended semantics,
prefer clarifying the source over compensating only in ASI.

Worker restriction
------------------
Workers do not edit canonical source documents during extraction unless the
assignment explicitly instructs them to do source-document patch work.

Workers may add or update candidates in this file when extraction exposes a
possible source-document clarity issue.

Candidate status values
-----------------------
CANDIDATE
  Recorded for supervisor review.

ASI_ONLY
  Supervisor decided the issue belongs only in assistant indexes or extraction
  wording.

SOURCE_FIX_RECOMMENDED
  Supervisor decided the canonical source document should be patched.

BOTH_RECOMMENDED
  Supervisor decided both source and ASI/index changes are useful.

DEFERRED
  Supervisor deferred the decision until related documents are extracted.

REJECTED
  Supervisor decided no change is needed.

APPLIED
  The approved source or ASI fix has been applied.

Problem type values
-------------------
Use one or more:
- ambiguity
- missing boundary
- term confusion
- cross-document mismatch
- weak retrieval wording
- possible semantic gap
- extraction wording only

Fix target values
-----------------
Use one:
- ASI only
- source document
- both ASI and source document
- needs supervisor decision
- defer until related documents are extracted
