Turnix Assistant Semantic Index thread launch templates
=======================================================

Purpose
-------
This file provides copy-paste launch prompts for Assistant Semantic Index
supervisor, worker, audit, inferred-term review, source-patch, ASI-generation,
and test threads.

It is non-authoritative workflow convenience text. It does not define Turnix
semantics.

Branch
------
CHATGPT_EXTRACT_INDEX

General use
-----------
Copy the relevant template into a new thread and replace placeholder values.

The templates are intentionally short. The authoritative workflow instructions
live in the prompt files that the new thread is instructed to load.

Template: inferred-term review thread
-------------------------------------
Use this for cloud-oriented review of useful or misleading terms inferred by
extraction or ASI generation but not clearly present in source.

BEGIN TEMPLATE

We are working on the Turnix Assistant Semantic Index workflow.

Prefer a strong cloud LLM for this task.

Load from my GitHub repository, branch CHATGPT_EXTRACT_INDEX:
- docs/AI_WORKFLOW_BOOTSTRAP.txt
- docs/CMR-04_CANONICAL_INDEX_TURNIX_SPECIFICATION.txt
- docs/design/ai/indexes/work/ASI-WORKFLOW_REHYDRATION.txt
- docs/design/ai/indexes/work/ASI-INFERRED_TERM_REVIEW_PROMPT.txt
- docs/design/ai/indexes/work/ASI-INFERRED_TERM_CANDIDATES.txt

Classify every loaded file as COMPLETE before using it.

Your role is inferred-term review thread.
Your assigned source document is: <DOC_ID>
Your assigned generated material is:
- <EXTRACTION_OR_ASI_FILE_1>
- <EXTRACTION_OR_ASI_FILE_2>

Assignment:
Compare the assigned source document against the assigned generated material.
Find high-value terms used by generated material that are not present in the
source document, or are present only in a different form.

Classify candidates as:
- EXPLICIT_SOURCE_TERM
- SUPPORTED_INFERRED_TERM
- CANONICAL_TERM_CANDIDATE
- INDEX_ALIAS_ONLY
- REJECT_OR_REPLACE

Record useful candidates in:
- docs/design/ai/indexes/work/ASI-INFERRED_TERM_CANDIDATES.txt

Rules:
- Do not patch source documents.
- Do not edit extraction records.
- Do not edit ASI index files.
- Do not approve candidates; supervisor/user decides implementation.
- Focus on CamelCase, PascalCase, capitalized domain terms, HIGH_VALUE_TERMS,
  routing terms, repeated terms, and object/type/schema/event/span/record/id
  names.

END TEMPLATE
