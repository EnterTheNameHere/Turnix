Turnix Assistant Semantic Index workflow status ledger
======================================================

Purpose
-------
This file records progress for the Assistant Semantic Index extraction project.

It is non-authoritative workflow state. It does not define Turnix semantics.

Branch
------
CHATGPT_EXTRACT_INDEX

Ledger states
-------------
NOT_STARTED
  The document is known but no extraction record exists.

ASSIGNED
  A worker thread has been assigned the document but no accepted extraction
  record has been committed.

EXTRACTED
  A first extraction record exists.

REVIEWED
  The supervisor thread has reviewed the extraction record.

NEEDS_REVISION
  The extraction record exists but needs correction or rework.

INDEXED
  The extraction record has been incorporated into one or more ASI index files.

BLOCKED
  Work cannot continue until a retrieval, authority, schema, or workflow issue
  is resolved.

Review states
-------------
UNREVIEWED
REVIEWED_OK
NEEDS_FIX
SUPERSEDED
