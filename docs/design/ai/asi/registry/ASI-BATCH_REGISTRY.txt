Turnix Assistant Semantic Index batch registry
==============================================

Purpose
-------
This file defines named document batches used by Assistant Semantic Index
workflows.

This file is non-authoritative workflow guidance. It does not define Turnix
semantics.

Batch rules
-----------
1. Batch IDs are stable workflow labels.
2. Batch IDs do not replace canonical DOC_ID values.
3. Batch membership is used for extraction planning, audit planning, index
   generation, and test setup.
4. Canonical document paths are resolved through CMR-04 when needed.
5. Extraction paths in this registry are ASI processed-output paths, not
   canonical source paths.
6. ASI-generated batch review filenames use uppercase machine-oriented names.
7. Batches should group documents by semantic and authority family, not by
   leftovers or processing convenience alone.
