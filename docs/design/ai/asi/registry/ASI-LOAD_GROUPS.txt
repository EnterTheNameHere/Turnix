Turnix Assistant Semantic Index load groups
===========================================

Purpose
-------
This file defines reusable file-load groups for Assistant Semantic Index
workflows.

Load groups reduce duplication across workflow prompts and registry entries.

This file is non-authoritative workflow guidance. It does not define Turnix
semantics.

General rules
-------------
1. A load group is a named list of files that a workflow must load before doing
   its assigned work.
2. Load groups do not grant write permission.
3. Load groups do not make loaded files authoritative beyond their own scope.
4. Every file in a required load group must be fetched and classified according
   to AI_WORKFLOW_BOOTSTRAP before use.
5. If a required load group cannot be loaded completely, the workflow stops and
   reports the failure.
