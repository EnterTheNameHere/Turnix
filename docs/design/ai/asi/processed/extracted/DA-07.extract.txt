Confusable terms
----------------
- IoManager vs Reader / Writer:
  IoManager owns persistence authority; Readers and Writers implement concrete
  format handling under IoManager control.
  CONFIDENCE: explicit
- Writable root vs mutation authority:
  A writable root permits persistence targets under root policy, but does not
  grant state-mutation authority by itself.
  CONFIDENCE: explicit
- Adapter-executed code vs persistence authority:
  Adapter-executed code may request persistence through mediated paths, but does
  not gain raw filesystem authority.
  CONFIDENCE: explicit
- Built-in provider vs extended provider:
  Built-in providers exist before discovery; extended providers require provider
  registration and activation of the providing pack.
  CONFIDENCE: explicit
- User-decidable vs optional / best-effort:
  User-decidable failures pause continuation for explicit recovery; optional
  failures affect non-authoritative artifacts such as logs, traces, or caches.
  CONFIDENCE: explicit
- Backup vs snapshot:
  Backups fit small critical files or prior versions; snapshots fit related
  multi-file or multi-artifact units.
  CONFIDENCE: explicit
- Migrator vs rollback:
  Migrators move persisted data forward; rollback safety comes from IoManager
  and the DA-04 commit model, not inverse migrator logic.
  CONFIDENCE: explicit
- Streaming write vs partial final output:
  Streaming write may stage incrementally, but cancellation must not create a
  partial valid final output.
  CONFIDENCE: explicit
- Streaming-kind examples vs locked future catalog:
  utf8TextStream, binaryStream, jsonlStream, tarStream, and saveSnapshotStream
  are examples and do not lock the full future streaming catalog.
  CONFIDENCE: explicit
