- TERM_PAIR: discovery vs resolution
  CONFIDENCE: explicit
  DISAMBIGUATION: DA-09 discovery identifies and classifies candidate pack
                  entities. DA-11/DA-13 handle later deterministic resolution,
                  source selection, selectors, and dependency satisfaction.

- TERM_PAIR: root origin kind vs root category
  CONFIDENCE: explicit
  DISAMBIGUATION: Origin kind says where a root came from. Category says which
                  semantic subdirectory is involved.

- TERM_PAIR: userdata/ vs content categories
  CONFIDENCE: explicit
  DISAMBIGUATION: userdata/ is persisted config/runtime/user state and is not a
                  content category.

- TERM_PAIR: saves/ vs content-root packs
  CONFIDENCE: explicit
  DISAMBIGUATION: saves/ contains SavePacks and save-context state. SavePacks are
                  discoverable as save entities, not importable as ordinary
                  content-root packs.

- TERM_PAIR: selected root vs preferred root
  CONFIDENCE: explicit
  DISAMBIGUATION: Selected root is explicit user choice. Preferred root is sticky
                  last-used usable operational target.

- TERM_PAIR: CLI userdata vs ENV userdata
  CONFIDENCE: explicit
  DISAMBIGUATION: CLI userdata is final and ignores relocation hints. ENV
                  userdata is a bootstrap seed and participates in normal
                  userdata bootstrap.

- TERM_PAIR: raw filesystem depth vs manifest-based discovery depth
  CONFIDENCE: explicit
  DISAMBIGUATION: Discovery depth is based on manifest nesting, not arbitrary
                  directory nesting.

- TERM_PAIR: ignored root-level manifest vs rejected pack candidate
  CONFIDENCE: explicit
  DISAMBIGUATION: A manifest directly in a category root is ignored because roots
                  are namespaces. Other invalid candidates may be rejected with
                  reasons.

- TERM_PAIR: duplicate manifest candidates vs additive field composition
  CONFIDENCE: explicit
  DISAMBIGUATION: Duplicate manifest candidates are selected or shadowed as whole
                  artifacts; fields are not merged across manifests.
