SOURCE_ROLE
-----------
DA-14 defines the boundary between inert pack metadata and Turnix-recognized
execution. It owns activation lifecycle semantics, PackContext authority during
activation, activation entrypoint rules, activation-vs-execution separation,
immediate execution unsupportedness, JavaScript runtime entry behavior,
orchestrated execution guarantees, activation trace obligations, and activation
failure / NotActivatedError handling.

PRIMARY_DOMAINS
---------------
- DOMAIN: activation lifecycle
  CONFIDENCE: explicit
  NOTES: Activation is the controlled transition from inert pack metadata into
        recognized executable participation under Turnix orchestration.

- DOMAIN: PackContext authority
  CONFIDENCE: explicit
  NOTES: PackContext is created only by Turnix, bound to one pack instance, and
        represents pack-facing execution authority without exposing raw Kernel
        internals.

- DOMAIN: activation entrypoint
  CONFIDENCE: explicit
  NOTES: onLoad(ctx) is the sole activation entrypoint and is called exactly
        once per pack instance by Turnix.

- DOMAIN: activation versus execution
  CONFIDENCE: explicit
  NOTES: Activation is one-time; later execution may happen many times only
        through Turnix orchestration when Turnix-recognized.

- DOMAIN: unsupported immediate execution
  CONFIDENCE: explicit
  NOTES: IIFE-style code, top-level side effects, module-level execution, and
        import-time behavior do not activate packs and are outside Turnix
        lifecycle guarantees.

- DOMAIN: JavaScript runtime entry semantics
  CONFIDENCE: explicit
  NOTES: runtimes.javascript.entry is the activation module imported by Turnix;
        runtimes.javascript.entries are library modules and are not activation
        entries.

- DOMAIN: orchestrated execution guarantees
  CONFIDENCE: explicit
  NOTES: Turnix guarantees execution behavior only when invoked and tracked
        through Turnix orchestration.

- DOMAIN: activation trace obligations
  CONFIDENCE: explicit
  NOTES: DA-14 owns activation-domain trace reason identifiers and activation
        lifecycle outcome visibility.

- DOMAIN: activation failure and NotActivatedError
  CONFIDENCE: explicit
  NOTES: Activation failure leaves the pack inactive, blocks dependent
        activation, surfaces to the user, and forbids silent fallback.
