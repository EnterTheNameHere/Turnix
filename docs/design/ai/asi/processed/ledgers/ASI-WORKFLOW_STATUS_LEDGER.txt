Turnix Assistant Semantic Index workflow status ledger
======================================================

Purpose
-------
This file records ASI workflow status for extraction, audit, index generation,
and related workflow runs.

This file is non-authoritative workflow state. It does not define Turnix
semantics.

Maintenance
-----------
This file is workflow-maintained.

Manual edits are not expected unless a supervisor or user explicitly assigns
ledger maintenance.

Required existence
------------------
This file is persistent ASI workflow infrastructure.

It must exist before workflows that load workflow status can run.

It may be empty of entries, but it must still contain the format and status
rules needed by workers.

Mutation policy
---------------
This file is updated in place.

Existing entries are preserved unless they are explicitly updated, superseded,
or corrected by an assigned workflow or supervisor/user maintenance task.

Workers may update matching entries by DOC_ID and BATCH_ID.
Workers must not rewrite unrelated entries.

Generated extraction records are replaced as whole generated outputs, but this
ledger is not replaced wholesale by extraction workers.

Entry status values
-------------------
Expected status values include:
- PLANNED
- EXTRACTED
- AUDITED
- NEEDS_RERUN
- BLOCKED
- SUPERSEDED

Expected review state values include:
- UNREVIEWED
- REVIEWED
- ACCEPTED
- NEEDS_REVIEW
- NEEDS_SUPERVISOR_DECISION

Entry format
------------
Use this format for extraction workflow status entries:

BEGIN_ENTRY
DOC_ID:
BATCH_ID:
CANONICAL_SOURCE_FILE:
EXTRACTION_FILE:
SOURCE_DOC_REV:
SOURCE_DOC_GIT:
FETCH_SHA:
EXTRACTION_REV:
STATUS:
REVIEW_STATE:
LAST_WORKFLOW_ID:
LAST_WORKFLOW_REF:
NOTES:
END_ENTRY

Field rules
-----------
DOC_ID:
Canonical Turnix document ID for the extraction record.

BATCH_ID:
ASI batch that assigned or owns this extraction run.

CANONICAL_SOURCE_FILE:
Canonical source path resolved through CMR-04.

EXTRACTION_FILE:
Generated ASI extraction record path.

SOURCE_DOC_REV:
DOC_REV found in the source document when available.

SOURCE_DOC_GIT:
DOC_GIT found in the source document when available.

FETCH_SHA:
Repository blob SHA or retrieval identity for the source used by the workflow.

EXTRACTION_REV:
Revision of the generated extraction record.

STATUS:
One of the expected status values.

REVIEW_STATE:
One of the expected review state values.

LAST_WORKFLOW_ID:
Workflow ID that last updated the entry.

LAST_WORKFLOW_REF:
Commit, branch, run note, or placeholder identifying the last update when
available.

NOTES:
Compact notes. Use "-" when empty.

Migration/reset note
--------------------
This new ASI structure was reorganized from earlier ASI workflow material.

Some migrated generated outputs may already exist under processed/ before this
ledger has entries for the corresponding workflow runs.

Do not infer that migrated outputs were produced by a clean run of the new
workflow contract unless a matching ledger entry says so.

When migrated outputs are regenerated through the new workflow system, add or
update their entries here.
