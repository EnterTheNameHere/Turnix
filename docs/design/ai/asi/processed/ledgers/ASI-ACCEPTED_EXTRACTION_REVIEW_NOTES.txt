Turnix Assistant Semantic Index accepted extraction review notes
===============================================================

Purpose
-------
This file records accepted extraction-review requirements that worker threads
must preserve when regenerating extraction records or final ASI index files.

It is non-authoritative workflow/control guidance. It does not define Turnix
semantics.

Why this file exists
--------------------
Extraction records are disposable generated artifacts. A worker may replace an
entire extraction record during rerun.

Therefore, accepted review findings must not live only inside extraction
records. They must be recorded in durable workflow/control files so future
workers can regenerate outputs without losing accepted improvements.

Usage rule
----------
Worker threads must load this file before regenerating extraction records or ASI
index files.

If this file contains requirements for a document or batch, the worker must
preserve those requirements unless the assignment explicitly supersedes them.

A previous extraction record may be used as a reference, but it is not the
source of truth for accepted review requirements.

Requirement status values
-------------------------
ACCEPTED
  Preserve in future generated output.

SUPERSEDED
  Do not preserve as written; a later requirement replaces it.

DEFERRED
  Not yet required in generated output.

REJECTED
  Reviewed and intentionally not required.

APPLIED_TO_SOURCE
  Source document was updated so future extraction should derive the finding
  from source, but ASI routing may still keep a compact trap if useful.
