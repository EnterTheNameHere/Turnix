Turnix Assistant Semantic Index generated index ledger
======================================================

Purpose
-------
This file records generated ASI index files, their input batches, and their
review state.

This file is non-authoritative workflow state. It does not define Turnix
semantics.

Maintenance
-----------
This file is workflow-maintained by ASI index generation or supervisor workflows.

Manual edits are not expected unless a supervisor or user explicitly assigns
ledger maintenance.

Required existence
------------------
This file is persistent ASI workflow infrastructure.

It must exist before workflows that load generated-index state can run.

It may contain placeholder entries, but it must still contain the format and
status rules needed by workers.

Mutation policy
---------------
This file is updated in place.

Existing entries are preserved unless they are explicitly updated, superseded,
or corrected by an assigned workflow or supervisor/user maintenance task.

Index-generation workers may update matching entries by ASI_OUTPUT_FILE.
Workers must not rewrite unrelated entries.

Generated ASI index files may be replaced as whole generated outputs by
asi.index.generate, but this ledger is not replaced wholesale by index-generation
workers.

Entry status values
-------------------
Expected status values include:
- PLANNED
- PLACEHOLDER
- GENERATED
- REVIEWED
- TESTED_PASS
- NEEDS_REGENERATION
- BLOCKED
- SUPERSEDED

Test status values
------------------
Expected test status values include:
- NOT_TESTED
- PASSED
- FAILED
- PARTIAL
- NEEDS_RETEST
- NOT_APPLICABLE

Content status values
---------------------
Expected content status values include:
- NOT_GENERATED
- PARTIAL
- GENERATED
- SUPERSEDED

Entry format
------------
Use this format for generated ASI index entries:

BEGIN_ENTRY
ASI_OUTPUT_FILE:
SOURCE_BATCHES:
INPUT_EXTRACTION_RECORDS:
AUDIT_REPORT:
ACCEPTED_REQUIREMENTS:
GENERATION_REV:
STATUS:
CONTENT_STATUS:
TEST_STATUS:
LAST_WORKFLOW_ID:
LAST_WORKFLOW_REF:
NOTES:
END_ENTRY

Field rules
-----------
ASI_OUTPUT_FILE:
Generated ASI index file path or filename.

SOURCE_BATCHES:
Batch IDs used as input. Use ";" to separate multiple batches.

INPUT_EXTRACTION_RECORDS:
Extraction records used as input. Use ";" to separate multiple files. Use "-"
when the entry is only a placeholder.

AUDIT_REPORT:
Audit report used when applicable. Use "-" when absent or not applicable.

ACCEPTED_REQUIREMENTS:
Accepted review requirement IDs applied. Use "-" when none or not applicable.

GENERATION_REV:
Revision or generation marker for the ASI output file.

STATUS:
One of the expected entry status values.

CONTENT_STATUS:
One of the expected content status values.

TEST_STATUS:
One of the expected test status values.

LAST_WORKFLOW_ID:
Workflow ID that last updated the entry.

LAST_WORKFLOW_REF:
Commit, branch, run note, or placeholder identifying the last update when
available.

NOTES:
Compact notes. Use "-" when empty.
